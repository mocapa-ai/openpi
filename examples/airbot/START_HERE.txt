1. Test the simple validation script:

   cd ~/openpi
   uv run python examples/airbot/validate_simple.py \
       --checkpoint_dir=checkpoints/airbot_pi05/20000 \
       --max_timesteps=10

   ✅ If it loads the policy → Your model is ready!

   cat ~/openpi/examples/airbot/SINGLE_PC_SETUP.md

   vim ~/openpi/examples/airbot/validate_simple.py
   # Edit the RobotInterface class:

   #   - set_action() - Send commands to robot motors
   #   - reset() - Return to home position

   cd ~/openpi
